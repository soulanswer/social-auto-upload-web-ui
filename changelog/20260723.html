v1.3.0

定时任务主线并入发布主流程，账号运营数据与视频号活动能力同步到同一版本面

这是一次真正的合流版发布说明，而不是 upstream v1.2.3 的重复包装。 本版同时保留 hn_gx 的定时任务、诊断日志、发布时间校验与结果判定， 并同步 master 的账号运营数据、视频号活动搜索、左侧栏交互强化和标题自动填充层级语义。

主线版本 1.3.0
合流方向 hn_gx ← master
核心原则 hn_gx 为主，master 补缺
New Core

这次真正新增 / 并入了什么

  • 定时任务全链路：导入发布配置、新建任务、详情、重跑、SSE 实时刷新。
  • 账号运营数据同步：账号管理页支持多平台 stats 卡片展示。
  • 视频号活动搜索：发布页可按活动名 / 发起人参与活动，并进入后端发布链路。
  • 统一搜索组件优化：2 秒自动搜索、卡片式布局、紧凑间距和更稳定的标签输入。

Release Notes

合并后应优先回归的场景

01
账号资料同步

优先确认支付宝和视频号账号资料同步时，`stats` 和 `storage_state` 都能正确回写。

02
发布中心直接发布

重点检查视频号活动、合集、位置、标题自动填充层级，以及账号个性化模式下的字段写入语义。

03
定时任务链路

验证导入发布配置、新建任务、详情查看、SSE 实时刷新，以及视频号活动字段在定时执行时不丢失。

04
平台稳定性回归

至少复测头条号、腾讯视频、小红书、视频号这几条近期变更最密集的路径。

Decision

版本结论

为什么不是 upstream v1.2.3

因为当前工作区已经不仅包含 upstream 的账号数据和视频号活动， 还包含 `hn_gx` 的定时任务、诊断日志、发布时间校验、结果判定与多项平台修复。 继续沿用 1.2.3 会低估这次发布的真实范围。

为什么定为 v1.3.0

这是一次主线能力面重组：新增的不是单一 patch，而是“发布中心 + 定时任务 + 多平台数据同步 + 行为语义”的合流， 用一个新的 minor 版本表达更准确。

当前说明对应 2026-07-23 的合并发布版状态。 如果后续继续补回归结果或再调整版本文档，应基于本页继续迭代，而不是回退到 upstream 的 `20260721 / v1.2.3` 文案。
